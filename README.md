# Тренажёр NumPy

Тренажёр по 24 заданиям из учебного блокнота + «нулевая» строка подключения библиотеки. На каждое задание — три режима:

- **Учить** — код целиком с подсветкой, построчный разбор простыми словами, пример вывода.
- **Тренажёр** — печатаешь по памяти строка за строкой. Подсветка ошибок на лету, подсказки «показать строку» и «подставить букву».
- **Экзамен** — пишешь весь код по памяти, затем построчное сравнение с эталоном и процент совпадения.

Прогресс сохраняется в `localStorage` браузера — ничего никуда не улетает.

## Как запустить

Один файл, никакой сборки. Открой `index.html` в браузере — всё.

## Как опубликовать на GitHub Pages

1. Создай пустой репозиторий на GitHub (например, `numpy-trainer`).
2. Залей в него `index.html`, `README.md` и `.nojekyll` (хоть через веб-интерфейс «Add file → Upload files», хоть через `git push`).
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `root` → Save.**

Через минуту-две страница будет доступна по адресу вида `https://<твой-ник>.github.io/numpy-trainer/`.

## Файлы

- `index.html` — тренажёр целиком (HTML + CSS + JS в одном файле).
- `.nojekyll` — говорит GitHub Pages не обрабатывать содержимое Jekyll'ом.
- `README.md` — этот файл.
